# 🎮 Hakchi3 — Полная русификация Hakchi2-CE

![License](https://img.shields.io/badge/license-GPL--3.0-blue.svg) ![Version](https://img.shields.io/badge/version-v0.2.0-green.svg) ![Platform](https://img.shields.io/badge/platform-Windows-lightgrey.svg) ![Language](https://img.shields.io/badge/language-C%23%20%2B%20C-purple.svg) ![Status](https://img.shields.io/badge/status-Active-success.svg)

## 📖 О проекте

**Hakchi3** — это неофициальный, полностью русифицированный форк популярной утилиты **Hakchi2-CE** (Community Edition), предназначенной для модификации и расширения возможностей ретро-консолей **NES Classic Edition**, **SNES Classic Edition** и **Sega Genesis/Mega Drive Mini**【turn0search9】. Проект базируется на версии **v3.9.3** оригинального Hakchi2-CE от TeamShinkansen и поддерживается независимым разработчиком【turn0fetch0】【turn0search5】.

> ⚠️ **Внимание**: Это **не официальный релиз** от команды TeamShinkansen. Все права на оригинальный код принадлежат их авторам, ClusterM и TeamShinkansen【turn0fetch0】.

### 🌟 Ключевые особенности

-   **🇷🇺 Полная русификация интерфейса** — все элементы управления, меню и сообщения переведены на русский язык, что делает процесс модификации доступным для русскоязычных пользователей.
-   **🔧 Обновление и замена уязвимых NuGet-пакетов** — проект включает обновления зависимостей для повышения безопасности и стабильности【turn0fetch0】.
-   **🚀 Переход на современную платформу .NET8** — кодовая база мигрирована на более новую версию .NET, что обеспечивает лучшую производительность и совместимость【turn0fetch0】.
-   **📋 Сохранение всех функций оригинала** — Hakchi3 наследует весь мощный функционал Hakchi2-CE, включая:
    -   Добавление дополнительных игр и контента на консоль【turn0search9】.
    -   Поддержку различных модулей (hmod) из репозиториев, таких как KMFD mod hub【turn0search14】.
    -   Возможность запуска эмуляторов других систем (MAME, Game Boy Advance и др.)【turn0search13】.
    -   Настройку фильтров, шейдеров и других улучшений изображения【turn0search13】.
-   **📜 Соответствие лицензии** — Проект распространяется строго под лицензией **GPL-3.0**, как и оригинальный Hakchi2-CE【turn0fetch0】.

## 📥 Установка и использование

### 📋 Требования

-   Операционная система: **Windows** (рекомендуется Windows 10/11)
-   Консоль: Одна из поддерживаемых ретро-консолей【turn0search9】
-   USB-кабель для подключения консоли к компьютеру (используйте качественный кабель, чтобы избежать ошибок【turn0search18】)
-   **.NET 8.0 Desktop Runtime** (устанавливается автоматически с программой или может быть скачан отдельно)

### 🚀 Быстрый старт

1.  **Скачайте последнюю версию** из раздела [Releases](https://github.com/Exeqtr-RED/Hakchi3/releases) в этом репозитории.
2.  **Распакуйте архив** и запустите `Hakchi3.exe`.
3.  **Подключите вашу ретро-консоль** к компьютеру с помощью USB-кабеля **в выключенном состоянии**.
4.  **Включите консоль**. Hakchi3 должен автоматически определить устройство.
5.  **Следуйте инструкциям** в русифицированном интерфейсе для добавления игр, установки модулей и настройки консоли.

> 💡 **Подсказка**: Для первого подключения может потребоваться установка драйверов (через встроенный в Hakchi инструмент "Установка драйверов").

<details>
<summary>🔧 Расширенные настройки и Troubleshooting</summary>

-   **Ошибка "Taking too long to boot"**: Чаще всего связана с некачественным USB-кабелем или слабым контактом. Попробуйте использовать другой кабель или порт USB на компьютере【turn0search18】.
-   **Проблемы с MAME-играми**: Убедитесь, что вы используете правильные ROM-файлы и настроенные эмуляторы. Некоторые игры могут требовать дополнительных настроек или конкретных версий ядер【turn0search13】.
-   **Миграция на новый компьютер**: Для переноса настроек и игр Hakchi на другой ПК, скопируйте папку `hakchi` из директории программы (обычно в `AppData`). Подробности обсуждаются в сообществе【turn0search15】.
-   **Установка модулей (hmod)**: Скачайте нужный модуль (например, шейдеры для GBA【turn0search13】) и поместите его папку в `user_mods` внутри директории Hakchi. Затем в программе выберите "Установить дополнительные модули".

</details>

## ⚙️ Технические детали и архитектура

Проект Hakchi3 написан на **C#** (66.4%) и **C** (27.3%) с использованием технологий Windows Forms для графического интерфейса【turn0fetch0】.

### 🏗️ Структура репозитория

```
Hakchi3/
├── 📁 .github/                # Конфигурация GitHub (actions, issue templates)
├── 📁 Installer/              # Файлы установщика (NSIS)
├── 📁 Libraries/              # Сторонние библиотеки
├── 📁 NSI/                    # Скрипты NSIS для создания инсталлятора
├── 📁 Scrapers/               # Модули для парсинга обложек и информации об играх
├── 📁 Web Installer/          # Компоненты для веб-установщика
├── 📁 ZIP Files/              # Утилиты для работы с ZIP-архивами
├── 📁 Zipper/                 # Дополнительные инструменты для сжатия
├── 📁 ce-data/                # Данные и конфигурации Community Edition
├── 📁 driver/source/          # Исходный код драйвера для консолей
├── 📁 hakchi_gui/             # Основной графический интерфейс (C#)
├── 📁 libwdi/                 # Библиотека для работы с USB-устройствами
├── 📁 tools/                  # Вспомогательные утилиты
├── 📄 hakchi_gui.sln          # Решение Visual Studio
├── 📄 LICENSE                 # Файл лицензии (GPL-3.0)
└── 📄 README.md               # Этот файл
```

### 🔄 Ключевые изменения по сравнению с оригиналом

1.  **Миграция на .NET8**: Код портирован с более старой версии .NET Framework на современный .NET8, что обеспечивает лучшую производительность, безопасность и кроссплатформенный потенциал (хотя в текущей версии ориентирован на Windows)【turn0fetch0】【turn0search17】.
2.  **Обновление зависимостей**: Заменены или обновлены потенциально уязвимые NuGet-пакеты, что повышает общую безопасность приложения【turn0fetch0】.
3.  **Локализация**: Все строки интерфейса, сообщения об ошибках и подсказки переведены на русский язык, что достигается через ресурсы (.resx) и отдельные файлы локализации.
4.  **Сборка и распространение**: Проект использует собственный инсталлятор на основе NSIS для удобной установки пользователями.
